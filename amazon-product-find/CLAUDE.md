# 亚马逊自动化选品 Agent

## 项目目标

AI 驱动的亚马逊选品，核心目标：**发现蓝海产品机会**。

## 目标市场

| 优先级 | 站点 |
|--------|------|
| 高 | 加拿大(CA)、澳大利亚(AU)、墨西哥(MX)、巴西(BR)、英国(UK)、中东(AE/SA) |
| 中 | 欧洲小国站点 |
| 低（但不排除） | 美国(US)、德国(DE) |

## 选品核心理念

**需求驱动，关键词为中心。不使用节点分类体系选品。** 从关键词出发，语义聚类锁定细分需求，再倒推产品形态。

## 选品流程（4阶段漏斗）

```
阶段1: 关键词挖掘与需求锁定
         ↓
阶段2: ABA分析 → 锁定产品形态（需求满足系数 = 转化占比/点击占比）
         ↓
阶段3: ROI粗算（采购成本 + FBA + 头程 + CPA）
         ↓ ROI不过关 → 淘汰
阶段4: 市场趋势研判 + 排除规则筛选
         ↓ 通过
      输出候选项目 → 用户审核
```

严格按阶段推进，不跳阶段。每阶段有明确 pass/fail 标准。

## 排除规则（阶段4硬性条件，命中任一即淘汰）

- 量价齐跌 → 市场萎缩，淘汰
- 量稳价跌 → 价格战，淘汰
- 量跌价稳 → 需求减少，淘汰
- 旱地拔葱（近3个月爆炸式增长） → 不可持续，淘汰

## 开发约定

- 所有金额统一 **美元(USD)**，站点本地货币按汇率转换
- 敏感信息（API Key、Token）放 `.env`，不进代码仓库
- 数据来源：用户手动从 Sorftime 网页端导出，贴给 AI 分析
- 报告输出到 `output/` 目录
